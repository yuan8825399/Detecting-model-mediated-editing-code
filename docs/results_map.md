## File conventions

* `results/*.csv` are UTF-8 **with BOM** so that Chinese column and category labels open
  correctly in Excel. Read them with `encoding="utf-8-sig"` (pandas and the scripts here
  already do). `results/*.json` are UTF-8 without BOM.
* `results/*.npy` / `*.npz` are prediction arrays and sets, stored so that figures can be
  rebuilt without refitting models.
* Figures are written twice: 300 dpi PNG and vector PDF.
