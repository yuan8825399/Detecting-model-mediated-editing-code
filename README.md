# provenance-audit

Code and data for **“Model-mediated editing and text detection in Chinese legal
abstracts”**: a fully crossed benchmark of 493 published legal abstracts revised by four
large language models under four editing instructions, together with the detectors,
reliability audits and the set-valued audit method (PAL-CP) reported in the paper.

## What this repository contains

| | |
|---|---|
| **Corpus** | 8,381 records: 493 human abstracts × (1 original + 4 instructions × 4 models), 2000–2020 |
| **Edits** | 7,888 model-edited variants with character-, sentence- and discourse-level measurements |
| **Detectors** | stylometric, character n-gram, fused, and a frozen-BERT probe |
| **Audits** | source isolation, calibration, cross-model/domain/era/intensity transfer |
| **Method** | PAL-CP: joint 17-cell provenance lattice + class-conditional conformal sets |
| **Outputs** | 15 tables and 9 figures, all regenerated by scripts, committed under `results/` and `figures/` |

## Headline results

| Quantity | Value |
|---|---|
| Presence detection, char n-gram | AUC 0.840 (95% CI 0.814–0.868) |
| Recall at the calibration-fixed operating point | 0.620 (realised FPR 0.093) |
| Recall / non-identical fraction, grammar correction | 0.154 / 0.637 |
| Recall / non-identical fraction, rewriting | 0.858 / 0.997 |
| Edit-type classification (4-class) | macro-F1 0.514 |
| Model attribution (4-class) | macro-F1 0.608 |
| Cross-model transfer | 0.841 in-domain → 0.683 transferred |
| PAL-CP silent errors | 333 → 104 per 1,000, abstaining on 19.7% |
| PAL-CP coverage (nominal 0.90) | 0.896; human class 0.849 |
| Coverage under generator shift | 0.660 (Kimi) to 0.912 (Doubao, ERNIE) |

Grammar correction left **33.3%** of outputs byte-identical to their source, and the
nominal four-level instruction ladder separates one condition from three rather than four.

## Quickstart

```bash
python -m pip install -r requirements.txt
python -m pip install -e .

pytest -q                                  # ~30 s
python analysis/40_isolation_audit.py      # 51 protocols, 0 document overlap
```

Rebuild Figures 1–9 from the committed results (no model fitting, ~30 s):

```bash
python scripts/run_pipeline.py --only typology,figures,figure-palcp,figure-coverage
```

The `typology` stage regenerates `processed/pairs.pkl`, the only intermediate the figure
scripts need; everything else they read is committed under `results/`.

Recompute the paper's numbers from the corpus:

```bash
python scripts/run_pipeline.py --stage core    # ~10 min
python scripts/run_pipeline.py --stage all     # ~60 min on 4 CPU cores
```

`python scripts/run_pipeline.py --list` shows every stage, its runtime and whether it fits
models. Details and troubleshooting: [`docs/reproduction.md`](docs/reproduction.md).

## The method

PAL-CP returns a **set** of admissible provenance verdicts instead of a single score.

1. **Joint lattice.** One multinomial logistic regression over the 17 provenance cells
   `{H0} ∪ {model × instruction}`; marginalising the posterior answers presence, edit type,
   edit intensity and model attribution from a single fit.
2. **Class-conditional conformal.** Nonconformity scores `1 − p` (edited) and `p` (human)
   are calibrated separately at level α, using the `⌈(n+1)(1−α)⌉`-th ordered score,
   or infinity when the required rank exceeds n.
3. **Set-valued output.** A text receives `present` if `1 − p ≤ q_pos`, `absent` if
   `p ≤ q_neg`; both or neither means *undecidable*. Coverage is evaluated empirically
   at five nominal levels and under generator shift. Correlated variants per source mean
   that source separation alone does not establish record-level exchangeability.

```python
from provenance.conformal import class_conditional_sets, verdicts
inc_present, inc_absent = class_conditional_sets(p_cal, y_cal, p_new, alpha=0.10)
```

## Data

`data/benchmark_records.jsonl` (22.8 MB) with fields documented in
[`docs/data_dictionary.md`](docs/data_dictionary.md). A metadata-only variant with the
text fields removed is provided for cases where the publisher terms do not permit
redistribution of the source abstracts; see [`LICENSE-DATA.md`](LICENSE-DATA.md).

Each record carries `input_sha256`, `output_sha256` and `title_sha256`; the test suite
verifies that every edited record's input hash matches its source's output hash.

## What is *not* reproducible here

The generation stage. The corpus records which system produced each variant and the content
hashes, but not the prompt text, decoding parameters, seeds, request timestamps or retry
logs (Table 1 of the paper). The analysis pipeline uses `analysis/` scripts and the
declared method-probe producer in `exploratory/` from the released corpus. See
[`docs/corrections_20261106.md`](docs/corrections_20261106.md) for the correction scope.

## Scope and limitations

* Chinese-language legal abstracts only; no claim about other languages or disciplines.
* Four vendor systems at the snapshots recorded in the data.
* **No human professional editing condition**: the study characterises model-mediated
  editing and does not establish whether detectors separate human from model revision at
  equal edit depth.
* PAL-CP “absent” verdicts are unreliable in the grammar-correction region by
  construction; this is reported as a finding, not treated as a defect.
